# Task 5.3 — Mini-map

## Goal
Add Unity's built-in `MiniMap` to the graph and let the user toggle / drag / resize
it via the toolbar.

## Files to edit
- `Editor/Graph/AsmDefGraphView.cs`
- `Editor/Window/AssemblyArchitectWindow.cs`

## Specification

### Construction
In `AsmDefGraphView` constructor, after `Insert(0, gridBackground)`:
```csharp
_miniMap = new MiniMap { anchored = true };
_miniMap.SetPosition(new Rect(15, 15, 200, 160));
Add(_miniMap);
```

### Public API
```csharp
public void SetMiniMapVisible(bool visible);
```
Sets `_miniMap.style.display = visible ? Flex : None;`.

### Window wiring
- Default visible.
- `_toolbar.MiniMapToggled += _graphView.SetMiniMapVisible;`
- Persist visibility in `[SerializeField] private bool _miniMapVisible = true;` and
  apply on `OnEnable`.

### Polish
- Use the same color palette as the rest of the package (override
  `_miniMap.style.borderTopColor` etc. via USS `aa-minimap` class and a couple of
  custom properties so it doesn't clash with the Editor theme).

## Acceptance criteria
- Toggle in the toolbar shows/hides the mini-map.
- Mini-map reflects node positions in real time.
- Visibility persists across domain reload.
- Console clean.

## Out of scope
- Custom mini-map rendering (use Unity's built-in).
