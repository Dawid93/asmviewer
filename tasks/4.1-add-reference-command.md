# Task 4.1 — `AddReferenceCommand`

## Goal
Turn the `EdgeAddRequested(sourceId, targetId)` event from the GraphView into an actual
edit of the source asmdef on disk, with validation and Undo.

## Files to create / edit
- `Editor/Commands/AddReferenceCommand.cs`
- Edit `Editor/Window/AssemblyArchitectWindow.cs` to wire it up.

## Specification

### Public surface
```csharp
internal sealed class AddReferenceCommand {
    public AddReferenceCommand(AsmDefRepository repo, AsmDefWriter writer);
    public void Execute(string sourceId, string targetId);
}
```

### Behavior
1. Resolve source/target via `repo.LoadAll()` + dictionary lookup.
   - If either is missing: log warning, return.
2. **Self-reference guard**: `sourceId == targetId` ⇒ silently ignore.
3. **Duplicate guard**: if source already references target (compare both `Name` and
   `GUID:`-prefixed forms), silently ignore.
4. **Built-in / read-only guard**: if source is a registry package or built-in,
   `EditorUtility.DisplayDialog("Read-only assembly",
     "Cannot modify a package not embedded in this project.", "OK")` and return.
5. **Cycle guard**: build current `DependencyGraphModel`, call
   `CycleDetector.WouldCreateCycle(model, sourceId, targetId)`. If true:
   ```csharp
   if (!EditorUtility.DisplayDialog(
         "Creates a dependency cycle",
         $"Adding {target.Name} as a reference of {source.Name} would create a cycle.\n"+
         "Add anyway?",
         "Add anyway", "Cancel"))
       return;
   ```
6. Mutate `source.References`: append `"GUID:" + target.Guid` if `target.Guid` is
   present, otherwise append `target.Name`.
7. Wrap the write in a single Undo group:
   ```csharp
   Undo.IncrementCurrentGroup();
   var groupId = Undo.GetCurrentGroup();
   Undo.SetCurrentGroupName($"Add Reference: {source.Name} → {target.Name}");
   writer.Save(source, "Add Assembly Reference");
   Undo.CollapseUndoOperations(groupId);
   ```
8. The repository's `AssetPostprocessor` will fire `Changed`, which triggers
   `Rebuild()` and the new edge appears.

### Window wiring
In `AssemblyArchitectWindow`:
```csharp
private AddReferenceCommand _addRefCmd;
// In OnEnable:
_addRefCmd = new AddReferenceCommand(_repo, new AsmDefWriter());
_graphView.EdgeAddRequested += _addRefCmd.Execute;
```

## Acceptance criteria
- Drawing an edge from A to B writes a new entry into A's asmdef on disk in the
  preferred `GUID:` form.
- Drawing an edge that would cycle pops the dialog; "Cancel" leaves files untouched.
- `Ctrl+Z` reverts the asmdef file to its previous JSON content **and** the graph
  rebuilds without the edge.
- Drawing the same edge twice is a no-op (no second write).
- Console clean.
