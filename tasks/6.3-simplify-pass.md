# Task 6.3 — Run the `simplify` skill across the package

## Goal
Trim the codebase before distribution: remove dead code, deduplicate helpers, ensure
the public API surface is minimal, and confirm every class has a single
responsibility.

## How to run
1. From the repository root, invoke the `simplify` skill on the package folder:
   ```
   /simplify Packages/com.<vendor>.assembly-architect/Editor/
   ```
2. Repeat for `Packages/com.<vendor>.assembly-architect/Tests/Editor/`.

## Mandatory checks (perform manually if the skill misses any)
- Every type in `Editor/` is `internal` unless explicitly meant to be consumed by
  external Unity scripts. The only justified `public` types are:
  - `AssemblyArchitectWindow` (so other tools can `GetWindow<>()` it — optional, keep
    `internal` if no consumer exists).
  - Public API enumerations only if there is documented external need.
  After review, downgrade everything else to `internal`.
- No `Debug.Log` left from earlier development (keep `Debug.LogWarning`/`LogError`
  only where they communicate real problems to the user).
- No `// TODO` left without a tracked task; convert leftover TODOs into a new
  Markdown file `tasks/backlog.md`.
- All `using System.Linq;` directives audited — keep only where actually used.
- Any helper that is referenced from exactly one place is inlined.
- Any 3-line "if (x == null) return;" guard is replaced with `?.` operator where
  semantics permit.

## Repository hygiene
- Verify there are zero `.meta`-less files: run a quick check by enumerating files
  under the package and asserting each has a sibling `.meta` (script the check in
  a one-off menu item for verification, then remove it).
- Run **Window ▸ General ▸ Console** ⇒ "Clear" then trigger a domain reload; expect
  zero warnings/errors after recompile.

## Acceptance criteria
- `simplify` reports no remaining issues, or every reported issue has a recorded
  rationale comment in the file.
- `git diff` shows only deletions / merges / minor renames; no behavior changes.
- Test suite from Task 6.1 + 6.2 still passes.
- Console clean.

## Out of scope
- Behavioral refactors that affect public API.
