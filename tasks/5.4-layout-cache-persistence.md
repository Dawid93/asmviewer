# Task 5.4 — Layout cache persistence

## Goal
Save user-arranged node positions and viewport state to disk so they survive Unity
restarts and can be checked into source control.

## Files to create / edit
- `Editor/Infrastructure/LayoutCache.cs`
- Edit `Editor/Window/AssemblyArchitectWindow.cs`

## Specification

### Storage location
```
ProjectSettings/Packages/com.<vendor>.assembly-architect/Layout.json
```
Create the folder if missing. This path is intentionally inside `ProjectSettings/` (not
`UserSettings/`) so positions can be shared by the team via VCS. A future polish task
may add a per-user toggle.

### File schema
```json
{
  "version": 1,
  "viewportPosition": { "x": 0.0, "y": 0.0 },
  "viewportScale": 1.0,
  "positions": [
    { "id": "GUID:abc123...", "x": 120.0, "y": 60.0 },
    { "id": "Foo.Bar",        "x": 420.0, "y": 60.0 }
  ]
}
```
- `id` is `AsmDefData.StableId` (preferring GUID).
- Versioned so we can migrate later.

### `LayoutCache`
```csharp
internal sealed class LayoutCache {
    public LayoutCache(IFileSystem fs = null);
    public LayoutCacheData Load();           // returns empty if file missing
    public void Save(LayoutCacheData data);
}

[Serializable] internal sealed class LayoutCacheData {
    public int Version = 1;
    public Vector2 ViewportPosition;
    public float ViewportScale = 1f;
    public PositionEntry[] Positions = Array.Empty<PositionEntry>();
}
[Serializable] internal struct PositionEntry { public string Id; public float X; public float Y; }
```
- Use `JsonUtility.ToJson(data, prettyPrint: true)` plus a manual sort of `Positions`
  by Id for deterministic diffs.

### Window integration
1. On `OnEnable`, `_cache = new LayoutCache(); _cacheData = _cache.Load();`. Seed
   `_positions` from `_cacheData`. After the first `Rebuild`, restore viewport via
   `_graphView.UpdateViewTransform(_cacheData.ViewportPosition, _cacheData.ViewportScale * Vector3.one)`.
2. After every `Rebuild`, schedule a debounced (500 ms) auto-save so casual moves
   persist without spamming disk.
3. `_toolbar.SaveLayoutRequested` triggers an immediate save and shows a tiny status
   message ("Layout saved.") in the status bar for 2 seconds.
4. Overflow menu **"Reset Layout"** clears the file and `_positions`, then calls
   `Rebuild()` so a fresh layout is computed.

### Capture viewport changes
Subscribe to `_graphView.viewTransformChanged += vt => _viewportDirty = true;` and
include those in the debounced save.

## Acceptance criteria
- Move a node, close & reopen Unity ⇒ node is in the same place.
- "Save Layout" produces a deterministic JSON file (alphabetic id order, stable
  formatting).
- "Reset Layout" deletes the file and re-runs the auto-layout.
- Adding a brand-new asmdef does not disturb existing positions.
- Console clean.

## Out of scope
- Per-user vs per-team toggle (Settings work, Task 5.5).
