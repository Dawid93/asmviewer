# Task 6.2 — Integration tests against the live Editor

## Goal
Verify end-to-end flows that involve the real `AssetDatabase`, `Undo`, and
`AsmDefWriter` round-trip.

## Files to create (under `Tests/Editor/`)
- `Integration/AddRemoveReferenceIntegrationTests.cs`
- `Integration/CreateAsmDefIntegrationTests.cs`
- `Integration/IntegrationFixtureBase.cs`

## Specification

### `IntegrationFixtureBase`
- `[OneTimeSetUp]`: create a unique sandbox folder
  `Assets/AssemblyArchitectTests_<guid>/` via `AssetDatabase.CreateFolder`.
- `[OneTimeTearDown]`: `AssetDatabase.DeleteAsset(sandboxPath)`.
- Helper `CreateAsmDef(string subPath, string name, params string[] refs)` writes a
  real asmdef file inside the sandbox and imports it.
- Helper `ReadAsmDef(string path)` returns parsed `AsmDefData`.

### `AddRemoveReferenceIntegrationTests`
1. **AddReference_WritesFileAndUpdatesGraph**
   - Create asmdefs `A` and `B`.
   - Construct `AsmDefRepository`, `AddReferenceCommand`, run `Execute(A.Id, B.Id)`.
   - Assert file `A.asmdef` on disk now contains `"GUID:<bGuid>"` in `references`.
   - Assert `repo.LoadAll()` reflects the change after refresh.
2. **AddReference_DuplicatesAreNoOps**
   - Run twice ⇒ second call must not modify the file (compare `File.GetLastWriteTime`).
3. **RemoveReference_ReversibleByUndo**
   - Add a reference, then remove it, then `Undo.PerformUndo()`.
   - Assert the reference is restored on disk.
4. **AddReference_CycleDialog_Cancel** (smoke test using a delegate seam — accept a
   `Func<DialogPrompt, bool>` injected via constructor; default uses
   `EditorUtility.DisplayDialog`.) Verify the file is **not** modified when the
   delegate returns false.

### `CreateAsmDefIntegrationTests`
1. **Create_NewAsmDefAppearsInRepository**.
2. **Create_WithAutoReference_AddsReferenceToParent**.
3. **Create_DuplicateName_ShowsErrorAndReturns**.

### Notes for tests
- Use `yield return null` (UnityTest) only if you need to wait for an
  `AssetDatabase.Refresh`. Most operations are synchronous.
- Wrap each test in try/finally that asserts the Console has no logged errors during
  the test (`LogAssert.NoUnexpectedReceived()`).

## Acceptance criteria
- All integration tests pass on a clean project import.
- Sandbox folder is fully cleaned up after the run (no leftover files in `Assets/`).
- Console clean.

## Out of scope
- Performance benchmarks.
- UI Toolkit visual tests.
