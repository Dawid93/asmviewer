# Task 1.1 — Define `AsmDefData` and JSON contracts

## Goal
Introduce a pure-C# data model that mirrors Unity's `.asmdef` JSON schema 1:1, so the
rest of the codebase can manipulate assembly definitions without touching disk or
Unity APIs.

## Files to create
- `Editor/Core/AsmDefData.cs`
- `Editor/Core/AsmDefOrigin.cs`
- `Editor/Core/VersionDefine.cs`

## Specification

### `AsmDefOrigin` (enum)
```
ProjectAssets   // path starts with Assets/
EmbeddedPackage // path starts with Packages/<id>/ AND folder is a real folder on disk inside the project
RegistryPackage // path starts with Packages/<id>/ AND folder lives under Library/PackageCache
BuiltIn         // built-in Unity module (no asmdef file on disk)
Unknown
```

### `VersionDefine` (struct, `[Serializable]`)
```
string Name        // e.g. "com.unity.entities"
string Expression  // e.g. "[1.0,2.0)"
string Define      // e.g. "ENTITIES_INSTALLED"
```

### `AsmDefData` (class, `[Serializable]`)
Field list — names must match Unity's JSON keys exactly so that `JsonUtility` round-trips
without a custom converter:
```
string Name;
string RootNamespace;
string[] References;          // entries may be a name or "GUID:xxxxxxxx..."
string[] IncludePlatforms;
string[] ExcludePlatforms;
bool AllowUnsafeCode;
bool AutoReferenced;
bool OverrideReferences;
string[] PrecompiledReferences;
string[] DefineConstraints;
VersionDefine[] VersionDefines;
bool NoEngineReferences;
```
Add **non-serialized** runtime metadata (do **not** write to JSON):
```
[NonSerialized] public string AssetPath;     // "Assets/Foo/Foo.asmdef" or "Packages/.../Foo.asmdef"
[NonSerialized] public string Guid;          // AssetDatabase guid
[NonSerialized] public AsmDefOrigin Origin;
```

### Methods
- `AsmDefData Clone()` — deep copy of arrays.
- `string StableId { get; }` — returns `Guid` if non-empty, otherwise `Name`.
- `bool ReferencesById(string id)` — true if `References` contains `id` either by name
  or `GUID:<id>` form.

### Conventions
- All arrays default to `Array.Empty<T>()` in the constructor; never expose `null`.
- Fields use `public` so `JsonUtility` can serialize them.
- XML doc comments on every public member.
- No `using UnityEditor` or `using UnityEngine` except `[Serializable]`
  (`UnityEngine.SerializeField` not needed; `[Serializable]` lives in `System`).

## Acceptance criteria
- Round-trip test (write later in Task 1.3) compiles against this type.
- `Clone()` produces an instance whose array fields are *new* references but contain
  equal values.
- Console clean.
- File-level XML doc on `AsmDefData` summarizing the schema link
  (https://docs.unity3d.com/Manual/ScriptCompilationAssemblyDefinitionFiles.html).
