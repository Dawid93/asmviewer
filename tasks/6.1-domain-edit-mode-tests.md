# Task 6.1 — Edit-mode tests for domain & infrastructure

## Goal
Solidify the domain layer with deterministic, hermetic tests that do not require a
real Unity project.

## Files to create (under `Tests/Editor/`)
- `AsmDefDataTests.cs`
- `AsmDefJsonSerializerTests.cs`
- `AsmDefRepositoryTests.cs` (using `FakeFileSystem`)
- `DependencyGraphModelTests.cs`
- `LayoutTests.cs` (extend the one from Task 1.6 if not already complete)

- `Helpers/AsmDefBuilders.cs`

## Specification

### `FakeFileSystem`
- In-memory dictionary `Dictionary<string, string>` keyed by path.
- Implements `IFileSystem`.
- Track number of `WriteAllText` calls per path so tests can assert "no double write".

### `AsmDefBuilders`
Tiny fluent helpers to keep tests readable:
```csharp
internal static class A {
    public static AsmDefData Def(string name, params string[] refs) { ... }
    public static AsmDefData Def(string name, string guid, string assetPath, params string[] refs) { ... }
}
```
