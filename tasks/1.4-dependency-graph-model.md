# Task 1.4 — Build the `DependencyGraphModel`

## Goal
Convert a list of `AsmDefData` into an immutable graph that the GraphView and the
analyzers will consume. Fully Unity-API-free so it can be unit-tested in isolation.

## Files to create
- `Editor/Core/DependencyGraphModel.cs`
- `Editor/Core/AsmDefNodeModel.cs`
- `Editor/Core/AsmDefEdgeModel.cs`
- `Editor/Core/MissingReferenceInfo.cs`

## Specification

### `AsmDefNodeModel`
```
string Id          // = AsmDefData.StableId
string Name
AsmDefOrigin Origin
string AssetPath
```

### `AsmDefEdgeModel`
```
string SourceId    // node that *has* the reference
string TargetId    // node being referenced
```

### `MissingReferenceInfo`
```
string SourceId
string MissingReference   // raw string from the asmdef ("GUID:abc..." or "Foo")
string Reason             // "guid not found" | "name not found"
```

### `DependencyGraphModel`
Immutable, constructed by a builder:
```csharp
public static DependencyGraphModel Build(IReadOnlyList<AsmDefData> data);
```
Public surface:
```
IReadOnlyList<AsmDefNodeModel> Nodes
IReadOnlyList<AsmDefEdgeModel> Edges
IReadOnlyList<MissingReferenceInfo> MissingReferences
IReadOnlyDictionary<string, AsmDefNodeModel> NodesById
IReadOnlyDictionary<string, IReadOnlyList<string>> Outgoing  // sourceId -> targetIds
IReadOnlyDictionary<string, IReadOnlyList<string>> Incoming
bool TryGetNode(string id, out AsmDefNodeModel node);
```

### Resolution rules
For every entry in `AsmDefData.References`:
- If it begins with `GUID:`, look up by guid (strip prefix).
- Else look up by name.
- If not found, append a `MissingReferenceInfo`. Do **not** create an edge.
- A self-reference (id equals owner's id) is dropped silently (Unity also rejects).

### Determinism
- `Nodes` sorted ascending by `Name` (case-insensitive).
- `Edges` sorted by `(SourceId, TargetId)`.
- `MissingReferences` sorted by `(SourceId, MissingReference)`.

## Acceptance criteria
- `Build(...)` is pure: same input ⇒ same output.
- Edit-mode test exercising:
  - empty input ⇒ empty model;
  - mixed GUID and name references that resolve;
  - dangling reference ⇒ shows up in `MissingReferences` only;
  - self-reference dropped.
- All collections truly immutable (cast attempts to writable interfaces throw).

## Out of scope
- Cycle detection (Task 1.5).
- Layout computation (Task 1.6).
