# Task 0.1 — Initialize package skeleton

## Goal
Create the empty UPM package layout for **Assembly Architect** so subsequent tasks have
a place to put files.

## Context
- Unity project lives at the repo root and uses Unity 6 (`6000.x`).
- The package will live under `Packages/com.<vendor>.assembly-architect/` so it is
  *embedded* — easy to iterate, but already a real UPM package.
- Pick a `<vendor>` id now (lowercase, no spaces, e.g. `acme`). Use it consistently
  in **every** future task. Record the chosen value in `CHANGELOG.md` under
  `[Unreleased]` so later agents can read it back.

## Steps
1. Create folder `Packages/com.<vendor>.assembly-architect/`.
2. Create `package.json` with these fields:
   - `name`: `com.<vendor>.assembly-architect`
   - `version`: `0.1.0`
   - `displayName`: `Assembly Architect`
   - `description`: short paragraph (1–3 sentences) describing the tool.
   - `unity`: `6000.0`
   - `author`: `{ "name": "<vendor>" }`
   - `keywords`: `["assembly", "asmdef", "graph", "architecture", "editor"]`
   - `category`: `Editor`
3. Create empty `README.md`, `CHANGELOG.md` (Keep-a-Changelog header with `[Unreleased]`
   section), `LICENSE.md` (MIT placeholder), `Third Party Notices.md` (empty stub).
4. Create the folder layout below; add `.gitkeep` to every empty directory:
   ```
   Editor/
     Core/
     Infrastructure/
     Commands/
     Window/
       Inspector/
     Graph/
     Analysis/
     Settings/
     Resources/
     UI/
   Tests/
     Editor/
   Samples~/
   Documentation~/
   ```
5. Create `Editor/AssemblyArchitect.Editor.asmdef` with:
   - `name`: `AssemblyArchitect.Editor`
   - `includePlatforms`: `["Editor"]`
   - `references`: `[]`
   - `autoReferenced`: `false`
6. Create `Tests/Editor/AssemblyArchitect.Tests.asmdef` with:
   - `name`: `AssemblyArchitect.Tests`
   - `includePlatforms`: `["Editor"]`
   - `references`: `["AssemblyArchitect.Editor"]`
   - `optionalUnityReferences`: `["TestAssemblies"]` *(or use `defineConstraints: ["UNITY_INCLUDE_TESTS"]` if Unity 6 schema requires it)*
7. Open the Unity Editor to let it generate `.meta` files for everything created.

## Acceptance criteria
- Console shows zero errors after Unity finishes importing the new package.
- The package is visible in **Window ▸ Package Manager ▸ In Project** with the chosen
  display name.
- `Packages/com.<vendor>.assembly-architect/package.json` exists and validates.
- `git status` after the task shows only additions inside the new package folder.

## Out of scope
- Any C# code (later tasks).
- Filling README content (covered by Task 7.2).
