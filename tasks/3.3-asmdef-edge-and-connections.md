# Task 3.3 — `AsmDefEdge` and edge interaction

## Goal
Custom edge type plus the logic that turns user-drawn / user-deleted edges into events
the command layer can act on.

## Files to create / edit
- `Editor/Graph/AsmDefEdge.cs`
- Edit `Editor/Graph/AsmDefGraphView.cs`

## Specification

### `AsmDefEdge`
```csharp
internal sealed class AsmDefEdge : Edge {
    public AsmDefEdge();
    public void ApplyState(EdgeVisualState state);
}

[Flags] internal enum EdgeVisualState {
    None     = 0,
    InCycle  = 1 << 0,
    Filtered = 1 << 1,
}
```
- Default style: 2px solid `#808080`.
- `aa-edge-cycle`: 2px dashed `#ff8c42`.
- `aa-edge-filtered`: opacity 0.2.

Add USS in `AsmDefGraphView.uss`. Override `Edge.UpdateEdgeControl` only if needed.

### `AsmDefGraphView` changes
1. Override `GetCompatiblePorts`:
   ```csharp
   public override List<Port> GetCompatiblePorts(Port startPort, NodeAdapter adapter) {
       var compatible = new List<Port>();
       foreach (var port in ports) {
           if (port == startPort) continue;
           if (port.node == startPort.node) continue;          // no self
           if (port.direction == startPort.direction) continue; // input↔output only
           compatible.Add(port);
       }
       return compatible;
   }
   ```
2. Wire `graphViewChanged` callback (assign `this.graphViewChanged = OnGraphViewChanged;`):
   - For each entry in `change.edgesToCreate`:
     - Replace it with an `AsmDefEdge` (`change.edgesToCreate[i] = new AsmDefEdge { output = ..., input = ... }`).
     - Capture `sourceId = (edge.output.node as AsmDefNode).AsmDefId` and same for target.
     - Emit `EdgeAddRequested(sourceId, targetId)`.
     - **Important**: do not actually let GraphView add the edge. Return a `change`
       with `edgesToCreate = null` so the command layer is the only writer. The graph
       will rebuild from the model after `AsmDefRepository.Changed` fires.
   - For each `IRemovable` in `change.elementsToRemove` that is an `AsmDefEdge`:
     - Capture both ids, emit `EdgeRemoveRequested(...)`, exclude the edge from the
       removal list (same reasoning — model is the source of truth).
   - For each `GraphElement` moved (key `change.movedElements`): if it's an `AsmDefNode`,
     emit `NodePositionChanged(node.AsmDefId, node.GetPosition().position)`.
3. Edge instantiation in `Populate` switches from plain `Edge` to `AsmDefEdge`.

### Debouncing position changes
Position events fire continuously while dragging. Create a tiny helper:
```csharp
internal sealed class Debouncer {
    public Debouncer(int milliseconds, Action callback);
    public void Bump();
}
```
- Implementation uses `EditorApplication.update += Tick` and a stopwatch. Each `Bump`
  resets the wall-clock target. After `milliseconds` of inactivity, fires `callback`.
- `AsmDefGraphView` keeps a `Dictionary<string, Vector2>` of pending positions and a
  single `Debouncer` (default `500 ms`) that, on fire, raises one
  `NodePositionChanged` per entry and clears the dict.

## Acceptance criteria
- Dragging from one output to another input fires `EdgeAddRequested` exactly once and
  does *not* leave a phantom edge in the graph.
- Selecting an edge and pressing Delete fires `EdgeRemoveRequested` exactly once.
- Moving a node fires `NodePositionChanged` only after ~500 ms of stillness.
- Cannot connect two outputs, two inputs, or a node to itself.
- Console clean.
