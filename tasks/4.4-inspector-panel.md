# Task 4.4 — Inspector panel binding

## Goal
Show details for the currently-selected node in the right-side inspector slot
(Task 2.1) and allow editing every asmdef field via `AsmDefWriter`.

## Files to create / edit
- `Editor/Window/Inspector/AsmDefInspectorPanel.cs`
- `Editor/UI/AsmDefInspectorPanel.uxml`
- `Editor/UI/AsmDefInspectorPanel.uss`
- Edit `Editor/Window/AssemblyArchitectWindow.cs` to host the panel and forward
  selection events.

## Specification

### `AsmDefInspectorPanel : VisualElement`
```csharp
public AsmDefInspectorPanel(AsmDefRepository repo, AsmDefWriter writer);
public void ShowFor(string asmDefId);
public void Clear();
```
- Loads `AsmDefInspectorPanel.uxml` once into itself.
- `ShowFor(null|"")` calls `Clear()`.
- Subscribes to `repo.Changed`; if the currently-displayed id still exists, refresh
  bindings; otherwise `Clear()`.

### Sections (top → bottom)
1. **Header**
   - Read-only name label.
   - Origin badge (Project / Embedded / Registry / Built-in).
   - "Ping" button → `EditorGUIUtility.PingObject` on the asset.
   - "Open in External Editor" button.
2. **General** (foldout, expanded by default)
   - `RootNamespace` (`TextField`).
   - `AllowUnsafeCode` (`Toggle`).
   - `AutoReferenced` (`Toggle`).
   - `OverrideReferences` (`Toggle`).
   - `NoEngineReferences` (`Toggle`).
3. **Platforms** (foldout)
   - Two `ListView`s: include / exclude. Items selected from a known platform list
     (`Editor`, `WindowsStandalone64`, `Android`, `iOS`, `LinuxStandalone64`,
     `macOSStandalone`, `WebGL`, ...). Use `EditorBuildSettings.installedTargets` if
     available, otherwise hard-code Unity's standard list.
   - Constraint: include and exclude cannot both be non-empty (Unity rejects).
4. **Define Constraints** (foldout) — `ListView<string>`.
5. **Version Defines** (foldout) — `ListView<VersionDefine>` with three columns
   (Name, Expression, Define). Use `MultiColumnListView`.
6. **Precompiled References** (foldout, read-only when `OverrideReferences = false`).
7. **References** (foldout, read-only summary list — adding/removing is via the graph).

### Edit pipeline
- All inputs go through a tiny helper:
  ```csharp
  void ApplyEdit(Action<AsmDefData> mutate, string undoLabel);
  ```
  which clones the current `AsmDefData`, mutates it, then calls
  `_writer.Save(clone, undoLabel)`.
- Use `RegisterValueChangedCallback` for fields. Debounce text fields (300 ms) so each
  keystroke does not write to disk.

### Window wiring
```csharp
private AsmDefInspectorPanel _inspector;
// In CreateGUI:
_inspector = new AsmDefInspectorPanel(_repo, new AsmDefWriter());
root.Q<VisualElement>("inspector-host").Add(_inspector);

// In OnEnable selection forwarding:
_graphView.NodeSelected += _inspector.ShowFor;
```

## Acceptance criteria
- Selecting a project asmdef populates every field correctly.
- Editing any field writes the change to disk after at most 300 ms (text) or
  immediately (toggle / list reorder).
- Undo restores the previous value of any field.
- Selecting a registry-package asmdef shows fields **disabled** (read-only) with a
  small note "Read-only (registry package)".
- Console clean.

## Out of scope
- Bulk multi-selection editing.
- Schema validation beyond the include/exclude mutual exclusion.
