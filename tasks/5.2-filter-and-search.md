# Task 5.2 — Filter and search

## Goal
Wire the toolbar's search field and origin toggles so the graph dims (or hides)
non-matching content while keeping the layout stable.

## Files to edit
- `Editor/Window/AssemblyArchitectWindow.cs`
- `Editor/Graph/AsmDefGraphView.cs`

## Specification

### Filter state
Add a small struct:
```csharp
internal readonly struct GraphFilter {
    public string SearchQuery;     // already lower-case, may be empty
    public bool ShowPackages;
    public bool ShowBuiltIns;
}
```

### Toolbar wiring (replacing the stubs from Task 2.2)
```csharp
_toolbar.SearchChanged       += q => UpdateFilter(_filter with { SearchQuery = (q ?? "").ToLowerInvariant() });
_toolbar.ShowPackagesChanged += b => UpdateFilter(_filter with { ShowPackages = b });
_toolbar.ShowBuiltInsChanged += b => UpdateFilter(_filter with { ShowBuiltIns = b });
```
`UpdateFilter` stores the filter on the window and calls
`_graphView.ApplyFilter(_filter)`.

### `AsmDefGraphView.ApplyFilter`
```csharp
public void ApplyFilter(GraphFilter filter);
```
Behavior:
- Determine which node ids should be **visible**:
  - Always visible if origin is `ProjectAssets`.
  - Visible if origin is `EmbeddedPackage` or `RegistryPackage` and `filter.ShowPackages`
    is true.
  - Visible if origin is `BuiltIn` and `filter.ShowBuiltIns` is true.
- Then apply the search query: if non-empty, a node passes only if `Name.ToLowerInvariant()`
  contains the query (simple substring match — fuzzy matching is a polish item).
- Hidden nodes:
  - If a node fails the **origin** filter ⇒ remove it from the graph entirely (it
    rebuilds on filter change is acceptable; faster: just `style.display = None`).
  - If a node fails only the **search** filter ⇒ keep visible but apply
    `NodeVisualState.Filtered`. Edges connected to filtered nodes get
    `EdgeVisualState.Filtered`.
- Edges connected to a hidden (origin-filtered) node should also be hidden
  (`style.display = None`).

### Performance
- `ApplyFilter` must not allocate per node — pre-compute a `HashSet<string>` of
  visible ids once and iterate.
- The search field already debounces inside `ToolbarSearchField`; do not add another
  debounce.

### Edge cases
- Search query of length 1 still applies (no minimum).
- Toggling "Show Packages" off while a package node is selected ⇒ deselect (no
  inspector for hidden nodes).

## Acceptance criteria
- Typing `unity` in the search field dims every node whose name does not contain
  "unity".
- Disabling "Show Packages" hides every package node and every edge connected to one.
- Re-enabling does **not** rebuild positions — nodes return to where they were.
- Filtered nodes do not affect cycle highlight (cycles are computed on the full
  graph; visualization is preserved).
- Console clean.

## Out of scope
- Fuzzy matching / scoring.
- Saved filter presets.
