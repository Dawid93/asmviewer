# Task 7.1 — Sample project

## Goal
Ship a tiny example so users can install the package, click "Import sample," and see
the tool work immediately on a known-good dataset.

## Files to create
- `Samples~/BasicProject/Readme.md`
- `Samples~/BasicProject/Acme.Core/Acme.Core.asmdef`
- `Samples~/BasicProject/Acme.Core/Placeholder.cs`
- `Samples~/BasicProject/Acme.Gameplay/Acme.Gameplay.asmdef` (references `Acme.Core`)
- `Samples~/BasicProject/Acme.Gameplay/Placeholder.cs`
- `Samples~/BasicProject/Acme.UI/Acme.UI.asmdef` (references `Acme.Core`,
  `Acme.Gameplay`)
- `Samples~/BasicProject/Acme.UI/Placeholder.cs`
- `Samples~/CycleDemo/Readme.md`
- `Samples~/CycleDemo/Acme.Cycle.A/Acme.Cycle.A.asmdef` (refs `Acme.Cycle.B`)
- `Samples~/CycleDemo/Acme.Cycle.A/Placeholder.cs`
- `Samples~/CycleDemo/Acme.Cycle.B/Acme.Cycle.B.asmdef` (refs `Acme.Cycle.A`)
- `Samples~/CycleDemo/Acme.Cycle.B/Placeholder.cs`

## `package.json` change
Add the `samples` array:
```json
"samples": [
  {
    "displayName": "Basic Project",
    "description": "A clean dependency tree across Core / Gameplay / UI assemblies.",
    "path": "Samples~/BasicProject"
  },
  {
    "displayName": "Cycle Demo",
    "description": "Demonstrates how the tool surfaces a deliberate dependency cycle.",
    "path": "Samples~/CycleDemo"
  }
]
```

## Specification
- `Placeholder.cs` files contain a single empty `internal class` so each asmdef
  produces a real assembly without errors when imported.
- The `~` suffix on `Samples~` keeps the contents excluded from compilation until
  explicitly imported via Package Manager.
- Each sample's `Readme.md` describes what the user should see when they open
  Assembly Architect after import.

## Acceptance criteria
- In a fresh project, installing the package, then **Package Manager ▸ Assembly
  Architect ▸ Samples ▸ Import** copies the chosen sample into `Assets/Samples/...`.
- Opening the Architect window after importing the **Basic Project** sample shows
  three nodes connected in a clean DAG.
- After importing the **Cycle Demo**, the cycle banner appears with one cycle
  highlighted in orange.
- Console clean.

## Out of scope
- Documentation page (Task 7.2).
- Gameplay logic in the placeholders.
