# Task 4.3 — `CreateAsmDefCommand` and right-click search menu

## Goal
Allow the user to create a brand-new `.asmdef` file from inside the graph: right-click
on empty space ⇒ "Create Assembly Definition…" ⇒ small modal popup ⇒ a new asmdef is
written, the graph rebuilds, and a node appears at the click location.

## Files to create / edit
- `Editor/Commands/CreateAsmDefCommand.cs`
- `Editor/Graph/AsmDefSearchProvider.cs`
- `Editor/Window/Dialogs/CreateAsmDefPopup.cs`
- Edit `Editor/Graph/AsmDefGraphView.cs` (context menu hook).

## Specification

### Right-click menu in `AsmDefGraphView`
Override `BuildContextualMenu(ContextualMenuPopulateEvent evt)`:
- If the click is on empty space (no element):
  ```csharp
  evt.menu.AppendAction("Create Assembly Definition…",
      _ => OpenCreatePopup(evt.localMousePosition));
  ```
- If the click is on an `AsmDefNode`, append:
  - `"Show in Project"` ⇒ `EditorGUIUtility.PingObject` on the asset.
  - `"Open .asmdef in External Editor"`.
  - `"Delete Assembly Definition"` (Phase 7 add-on; for now leave a stub that calls
    `Debug.LogWarning("Not implemented")`).

### `CreateAsmDefPopup : EditorWindow`
- Used as a popup (`ShowAsDropDown`).
- Fields:
  - **Folder** — `ObjectField` typed `DefaultAsset`, restricted via custom validator
    to only accept folders inside `Assets/`. Default = currently selected folder in
    Project, fallback `Assets/`.
  - **Name** — `TextField`, validated: non-empty, matches regex `^[A-Za-z_][A-Za-z0-9_.]*$`,
    not already in use as an asmdef name.
  - **Auto-reference selected node** — `Toggle`, default off; only enabled when there
    is exactly one node selected in the graph.
- Two buttons: **Create** (disabled until valid) and **Cancel**.
- On Create, dispatch `CreateAsmDefCommand.Execute(...)`.

### `CreateAsmDefCommand`
```csharp
internal sealed class CreateAsmDefCommand {
    public CreateAsmDefCommand(AsmDefRepository repo, AsmDefWriter writer);

    public sealed class Args {
        public string Folder;          // "Assets/Foo"
        public string Name;            // "Acme.Bar"
        public Vector2 GraphPosition;  // graph-space coords for the new node
        public string AutoReferenceFromSourceId; // optional
    }

    public void Execute(Args args);
}
```
Steps:
1. Construct an `AsmDefData` with `Name = args.Name`, all other defaults.
2. `path = $"{args.Folder.TrimEnd('/')}/{args.Name}.asmdef";`.
   - If file already exists, surface `EditorUtility.DisplayDialog("File exists", ...)`
     and return.
3. Use `Undo.IncrementCurrentGroup()` + group name "Create Assembly Definition".
4. Write file via `IFileSystem.WriteAllText` directly (no Undo for asset creation;
   Unity's `AssetDatabase.CreateAsset` doesn't apply to text files of this kind).
5. `AssetDatabase.ImportAsset(path)` then read the GUID via
   `AssetDatabase.AssetPathToGUID`. Update `data.Guid`/`data.AssetPath`.
6. If `AutoReferenceFromSourceId` provided, dispatch `AddReferenceCommand` for
   `sourceId → newAsmDef.StableId`. Re-use the same Undo group.
7. Persist the requested graph-space position into `_positions` so the node spawns
   exactly where the user clicked. Expose a small public method on the window:
   `void SetPendingPosition(string id, Vector2 pos)` that the command can call, or
   pass through a callback.

### `AsmDefSearchProvider` (optional but recommended)
- Implements `ISearchWindowProvider`. Single entry: "Create Assembly Definition…".
- Triggered by Spacebar in the graph (default GraphView shortcut).
- Calls the same `OpenCreatePopup` logic.

## Acceptance criteria
- Right-clicking empty graph space and choosing "Create Assembly Definition…" opens
  the popup pre-populated with a sensible folder.
- After Create, a new `.asmdef` file exists on disk, the graph contains a new node
  at the click position, and Undo (`Ctrl+Z`) deletes the file (or the import is
  reverted gracefully).
- Auto-reference toggle correctly creates a reference back to the previously-selected
  node.
- Console clean.

## Out of scope
- Deletion command (note: stub left for Phase 7 polish).
- Full file deletion via Undo — Unity's Undo for created text assets is best-effort;
  document the limitation in the popup tooltip.
