# Task 1.2 — Implement `AsmDefRepository`

## Goal
Provide the single source of truth for "all asmdefs currently in this project". The
repository scans the project, parses each asmdef into `AsmDefData`, and notifies
listeners when anything changes on disk.

## Files to create
- `Editor/Infrastructure/AsmDefRepository.cs`
- `Editor/Infrastructure/AsmDefAssetPostprocessor.cs`
- `Editor/Infrastructure/IFileSystem.cs`
- `Editor/Infrastructure/DefaultFileSystem.cs`

## Specification

### `IFileSystem`
Tiny seam so unit tests can avoid hitting the disk:
```csharp
internal interface IFileSystem {
    bool   Exists(string path);
    string ReadAllText(string path);
    void   WriteAllText(string path, string contents);
}
```
`DefaultFileSystem` is a thin wrapper over `System.IO.File`.

### `AsmDefRepository`
```csharp
internal sealed class AsmDefRepository {
    public AsmDefRepository(IFileSystem fs = null);
    public IReadOnlyList<AsmDefData> LoadAll();
    public AsmDefData FindByGuid(string guid);
    public AsmDefData FindByName(string name);
    public event Action Changed;
    internal void NotifyChanged();   // called by the AssetPostprocessor
}
```
- `LoadAll` runs `AssetDatabase.FindAssets("t:AssemblyDefinitionAsset")`, then for each
  GUID resolves `AssetDatabase.GUIDToAssetPath(guid)`, reads JSON via `IFileSystem`,
  and `JsonUtility.FromJson<AsmDefData>(...)`.
- Populate `AssetPath`, `Guid`, and `Origin`:
  - Path begins with `Assets/` ⇒ `ProjectAssets`.
  - Path begins with `Packages/` and the absolute resolved folder is **inside**
    `Library/PackageCache/` ⇒ `RegistryPackage`; otherwise ⇒ `EmbeddedPackage`.
- Result is cached. `LoadAll()` rebuilds only when `Changed` was fired since the last
  call, or when an internal `_dirty` flag is set.
- Reference resolution helper: `static string NormalizeReference(string entry)` — strips
  the `GUID:` prefix if present. Used by `FindByGuid`/`FindByName` callers.

### `AsmDefAssetPostprocessor : AssetPostprocessor`
- Override `OnPostprocessAllAssets`. If any imported, deleted, moved-from, or moved-to
  path ends with `.asmdef`, invoke `AsmDefRepository.Default.NotifyChanged()`.
- Define `AsmDefRepository.Default` as a static lazily-initialized singleton used by
  the EditorWindow (the test code can still construct its own instance with a fake
  `IFileSystem`).

## Acceptance criteria
- After domain code (Task 1.4) hooks into the repository, creating, renaming, deleting,
  or modifying any asmdef in the project causes `Changed` to fire exactly once per
  refresh batch.
- `Origin` is correctly classified for: an asmdef under `Assets/`, an embedded one
  under `Packages/<id>/`, and a registry one under `Library/PackageCache/<id>@version/`.
- Console clean.

## Out of scope
- Saving asmdefs back to disk (Task 1.3).
- Building the dependency graph (Task 1.4).
