# Task 1.3 — Implement `AsmDefWriter` with Undo support

## Goal
Persist changes back to `.asmdef` files in a way that:
1. Round-trips Unity's exact JSON format (so VCS diffs stay minimal).
2. Plays nicely with Editor Undo/Redo.
3. Triggers asset reimport automatically.

## Files to create
- `Editor/Infrastructure/AsmDefWriter.cs`
- `Editor/Infrastructure/AsmDefJsonSerializer.cs`

## Specification

### `AsmDefJsonSerializer`
- Public method `string Serialize(AsmDefData data)`.
- Output **must** match Unity's writer:
  - 4-space indent, LF line endings, trailing newline.
  - Key order identical to the official asmdef schema:
    `name, rootNamespace, references, includePlatforms, excludePlatforms,
     allowUnsafeCode, overrideReferences, precompiledReferences, autoReferenced,
     defineConstraints, versionDefines, noEngineReferences`.
  - Empty arrays serialize as `[]` (one line).
  - Bool fields default to `false` and are still emitted (Unity does emit them).
- Companion `AsmDefData Deserialize(string json)` for tests; production code may use
  `JsonUtility` for reading, but writes must go through this serializer to control
  formatting.
- Implementation hint: hand-rolled `StringBuilder` is simpler and more deterministic
  than `JsonUtility.ToJson(prettyPrint: true)`, which doesn't quote arrays the way
  Unity wants.

### `AsmDefWriter`
```csharp
internal sealed class AsmDefWriter {
    public AsmDefWriter(IFileSystem fs = null);
    public void Save(AsmDefData data, string undoLabel = "Modify Assembly Definition");
}
```
Behavior of `Save`:
1. Validate `data.AssetPath` is non-empty and points to an existing file.
2. Call `AssetDatabase.MakeEditable(data.AssetPath)` (returns false ⇒ throw with a
   user-friendly message including "is the file checked out?").
3. Serialize via `AsmDefJsonSerializer.Serialize(data)`.
4. Compare with current contents (via `IFileSystem.ReadAllText`); if identical, return
   early — no write, no reimport, no Undo bloat.
5. Locate the `AssemblyDefinitionAsset` via
   `AssetDatabase.LoadAssetAtPath<AssemblyDefinitionAsset>(...)`.
6. Wrap the write in `Undo.RegisterCompleteObjectUndo(asset, undoLabel)`.
7. `IFileSystem.WriteAllText(...)` then `AssetDatabase.ImportAsset(data.AssetPath)`.

## Acceptance criteria
- Edit-mode test: load an existing asmdef, mutate one bool, call `Save`, reload from
  disk, mutated value persisted, no other byte differs.
- Edit-mode test: calling `Save` twice with no change does *not* trigger a reimport
  (verify by counting calls to a fake `IFileSystem.WriteAllText`).
- Undo/Redo (`Ctrl+Z` / `Ctrl+Y` in the editor) restores the previous file content.
- Console clean.

## Out of scope
- Higher-level commands (Phase 4).
- UI feedback (Phase 5).
