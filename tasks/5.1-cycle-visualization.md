# Task 5.1 — Cycle visualization

## Goal
Surface the results of `CycleDetector` directly in the graph: cycle nodes/edges are
visually highlighted, and a banner tells the user how many cycles were found and
lets them focus on each one.

## Files to create / edit
- Edit `Editor/Window/AssemblyArchitectWindow.cs`
- Edit `Editor/Graph/AsmDefGraphView.cs`
- `Editor/Window/CycleBanner.cs`
- Update USS files for `aa-state-cycle` / `aa-edge-cycle`.

## Specification

### Detection
Inside `Rebuild()` (Task 3.4), after building `_model`:
```csharp
var cycles = CycleDetector.FindCycles(_model);
_graphView.ApplyCycleHighlight(cycles);
_cycleBanner.Update(cycles);
```

### `AsmDefGraphView.ApplyCycleHighlight`
```csharp
public void ApplyCycleHighlight(IReadOnlyList<IReadOnlyList<string>> cycles);
```
- Build a `HashSet<string>` of in-cycle node ids and a
  `HashSet<(string source, string target)>` of edges that lie inside any SCC.
- For each child node (`Node` enumerator filtered to `AsmDefNode`):
  call `node.ApplyState(NodeVisualState.InCycle)` if the id is in the set, else
  clear that flag.
- For each `AsmDefEdge`, set/unset `EdgeVisualState.InCycle`.

### `CycleBanner` (VisualElement)
- A thin strip placed directly under the toolbar, hidden when there are zero cycles.
- Layout: red icon + label `"⚠ {n} dependency cycle(s) detected — Focus next"` + a
  small `Button "Focus"`.
- Internal state: current cycle index. Each click on Focus advances modulo `cycles.Count`.
- Focus action:
  ```csharp
  void Focus(IReadOnlyList<string> cycle) {
      _graphView.ClearSelection();
      foreach (var id in cycle) {
          var node = _graphView.GetNodeById(id);
          if (node != null) _graphView.AddToSelection(node);
      }
      _graphView.FrameSelection();   // GraphView built-in
  }
  ```
- `GetNodeById` is a small helper added to `AsmDefGraphView`:
  ```csharp
  internal AsmDefNode GetNodeById(string id) =>
      nodes.OfType<AsmDefNode>().FirstOrDefault(n => n.AsmDefId == id);
  ```

### Window wiring
- Insert the banner just above the body region:
  ```csharp
  _cycleBanner = new CycleBanner(_graphView);
  root.Q<VisualElement>("toolbar").parent.Insert(1, _cycleBanner);
  ```
  *(Implementation detail: pick whichever placement keeps the cycle banner sticky
  and above the graph host without breaking the split view.)*

## Acceptance criteria
- A project with a deliberate 3-asmdef cycle shows orange borders on all three nodes
  and dashed orange edges between them.
- Banner reads `"⚠ 1 dependency cycle detected — Focus next"`. Clicking Focus frames
  exactly those three nodes.
- Multiple cycles cycle through with each click on Focus.
- Resolving the cycle (deleting the offending edge) immediately clears the banner.
- Console clean.
