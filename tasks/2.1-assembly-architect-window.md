# Task 2.1 — Create `AssemblyArchitectWindow`

## Goal
Add the `EditorWindow` shell. No graph yet — just the panes that later tasks fill in.

## Files to create
- `Editor/Window/AssemblyArchitectWindow.cs`
- `Editor/UI/AssemblyArchitectWindow.uxml`
- `Editor/UI/AssemblyArchitectWindow.uss`
- `Editor/Resources/Icons/window-icon.png` (16×16 + 32×32 retina; placeholder color block is fine)

## Specification

### `AssemblyArchitectWindow`
```csharp
internal sealed class AssemblyArchitectWindow : EditorWindow {
    [MenuItem("Window/Analysis/Assembly Architect")]
    public static void Open();

    private void CreateGUI();   // build UI Toolkit tree
    private void OnEnable();
    private void OnDisable();
}
```
- `Open()` calls `GetWindow<AssemblyArchitectWindow>()`, sets `titleContent` (text =
  "Assembly Architect", icon from `Resources/Icons/window-icon.png` via
  `EditorGUIUtility.IconContent` or `Resources.Load`).
- `minSize = new Vector2(900, 600)`.
- `CreateGUI`:
  1. Load `AssemblyArchitectWindow.uxml` with
     `AssetDatabase.LoadAssetAtPath<VisualTreeAsset>(
       "Packages/com.<vendor>.assembly-architect/Editor/UI/AssemblyArchitectWindow.uxml")`.
  2. Clone into `rootVisualElement`.
  3. Apply USS the same way.

### UXML layout
```
<UXML>

    <Toolbar name="toolbar" class="aa-toolbar"/>
    <VisualElement name="body" class="aa-body">

      <TwoPaneSplitView orientation="Horizontal"
                        fixed-pane-initial-dimension="320"
                        fixed-pane-index="1">
        <!-- left = graph-host (already above) - actually use TwoPaneSplitView at body level -->
        <VisualElement name="inspector-host" class="aa-inspector-host"/>
      </TwoPaneSplitView>
    </VisualElement>
    <VisualElement name="status-bar" class="aa-status-bar">
      <Label name="status-label" text="Ready"/>
    </VisualElement>
  </VisualElement>
</UXML>
```
*(Adjust the split-view to be the actual root of `body` so graph + inspector resize
together; the snippet above is illustrative.)*

### USS
- `aa-root` flex-grow:1, flex-direction:column.
- `aa-body` flex-grow:1.
- `aa-graph-host` flex-grow:1, min-width:400px, background-color:#1e1e1e dark, fallback
  light variant via `class="dark"` / `class="light"` set in `OnEnable` from
  `EditorGUIUtility.isProSkin`.
- `aa-inspector-host` width:320px, padding:8px, border-left:1px solid #3a3a3a.
- `aa-status-bar` height:22px, border-top:1px solid #3a3a3a, padding-left:8px.

### State persistence
- `[SerializeField] string lastSelectedNodeId` (used later).
- Window remembers split-view ratio via `SerializedProperty` on a hidden
  `ScriptableObject` saved with the window.

## Acceptance criteria
- Menu **Window ▸ Analysis ▸ Assembly Architect** opens the window.
- Window persists across domain reloads (open it, edit a script, recompile, window
  still there with same panes).
- Console clean.

## Out of scope
- Graph rendering (Phase 3).
- Toolbar functionality (Task 2.2 wires up controls).
