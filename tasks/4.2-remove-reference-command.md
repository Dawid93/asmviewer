# Task 4.2 — `RemoveReferenceCommand`

## Goal
Symmetric to Task 4.1: persist edge deletions back to disk with Undo.

## Files to create / edit
- `Editor/Commands/RemoveReferenceCommand.cs`
- Edit `Editor/Window/AssemblyArchitectWindow.cs` to wire it.

## Specification

### Public surface
```csharp
internal sealed class RemoveReferenceCommand {
    public RemoveReferenceCommand(AsmDefRepository repo, AsmDefWriter writer);
    public void Execute(string sourceId, string targetId);
}
```

### Behavior
1. Resolve source / target. Missing either ⇒ silent return.
2. **Read-only guard** identical to AddReference (registry package / built-in).
3. **Existence check**: if source does not reference target, silent return.
4. Optional confirmation: skip the dialog if the user holds Shift while pressing
   Delete on the edge. The GraphView passes a "force" flag through:
   - Update `EdgeRemoveRequested` event signature in Task 3.3 to
     `Action<string, string, bool>` (sourceId, targetId, skipConfirmation).
   - Detect `Event.current?.shift == true` at the moment the user presses Delete.
   - If `skipConfirmation` is false:
     ```csharp
     if (!EditorUtility.DisplayDialog(
            "Remove reference",
            $"Remove reference {target.Name} from {source.Name}?",
            "Remove", "Cancel")) return;
     ```
5. Remove the entry — match either `target.Name` or `"GUID:" + target.Guid`. Write
   the trimmed array back.
6. Undo group `"Remove Reference: {source.Name} → {target.Name}"`.

### Window wiring
```csharp
_removeRefCmd = new RemoveReferenceCommand(_repo, new AsmDefWriter());
_graphView.EdgeRemoveRequested += _removeRefCmd.Execute;
```

## Acceptance criteria
- Selecting an edge and pressing Delete prompts; "Remove" updates the file; "Cancel"
  does not.
- Holding Shift while deleting skips the prompt.
- Undo restores the reference and the visual edge.
- Console clean.

## Out of scope
- Bulk delete (multiple edges at once) — should already work because the graph fires
  one event per edge, but no extra UX is required here.
