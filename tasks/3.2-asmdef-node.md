# Task 3.2 — Create `AsmDefNode`

## Goal
Replace the plain `Node` placeholders from Task 3.1 with custom-styled nodes that
clearly communicate origin (project / package), state (broken / in-cycle), and a
single input + single output port.

## Files to create
- `Editor/Graph/AsmDefNode.cs`
- `Editor/UI/AsmDefNode.uss`

## Specification

### Class
```csharp
internal sealed class AsmDefNode : Node {
    public string AsmDefId { get; }
    public Port InputPort  { get; }
    public Port OutputPort { get; }

    public AsmDefNode(AsmDefNodeModel model);
    public void ApplyState(NodeVisualState state);
}

[Flags] internal enum NodeVisualState {
    None      = 0,
    InCycle   = 1 << 0,
    Broken    = 1 << 1,    // has missing references
    Filtered  = 1 << 2,    // dimmed by search
}
```

### Constructor
- Title = `model.Name`.
- Subtitle (small label below title) = origin string: `Project`, `Embedded Package`,
  `Registry Package`, `Built-in`.
- `userData = model.Id` (so `AsmDefGraphView` selection forwarding keeps working).
- Add USS class based on origin: `aa-origin-project`, `aa-origin-package-embedded`,
  `aa-origin-package-registry`, `aa-origin-builtin`.
- Disable the default expand/collapse caret (`titleButtonContainer.Clear()`).
- Add icon to the title (a small colored circle 8×8) representing origin.

### Ports
- `InputPort = Port.Create<Edge>(Orientation.Horizontal, Direction.Input,
                                 Port.Capacity.Multi, typeof(bool))` — `bool` is a
  throw-away type because GraphView ports are typed. Store as
  `inputContainer.Add(InputPort)`.
- `OutputPort` symmetric, added to `outputContainer`. Both labeled "" (no text).
- `port.portName = string.Empty;`.

### `ApplyState`
- Toggle USS classes:
  - `aa-state-cycle` when `InCycle`.
  - `aa-state-broken` when `Broken`.
  - `aa-state-filtered` when `Filtered` (sets opacity to 0.25).

### USS rules
- Default node background: `#2d2d30`.
- Project: left border 4px solid `#4ea1ff`.
- Embedded package: `#a06cff`.
- Registry package: `#888888`.
- Built-in: dashed border `#555555`.
- `aa-state-cycle` overrides border to `#ff8c42` and adds a subtle glow
  (`-unity-text-outline-color`).
- `aa-state-broken` overrides border to `#ff4d4d`.
- `aa-state-filtered` reduces opacity to `0.25`.

### Update `AsmDefGraphView.Populate`
Replace the plain `Node` instantiation with `new AsmDefNode(nodeModel)`. Use
`node.InputPort` / `node.OutputPort` when wiring edges.

## Acceptance criteria
- All four origins render with distinct colors.
- Calling `ApplyState(NodeVisualState.InCycle)` on a node changes its border at
  runtime without rebuilding the graph.
- Hidden expand caret no longer visible.
- Console clean.

## Out of scope
- Cycle detection wiring (Task 5.1).
- Edge styling (Task 3.3).
