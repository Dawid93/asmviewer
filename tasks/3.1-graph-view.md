# Task 3.1 — Create `AsmDefGraphView`

## Goal
Drop a working `GraphView` into the `graph-host` element from Task 2.1.

## Files to create
- `Editor/Graph/AsmDefGraphView.cs`
- `Editor/UI/AsmDefGraphView.uss`

## Specification

### Class
```csharp
internal sealed class AsmDefGraphView : GraphView {
    public AsmDefGraphView();
    public void Populate(DependencyGraphModel model,
                         IReadOnlyDictionary<string, Vector2> positions);
    public void Clear();
    public event Action<string> NodeSelected;   // emits the StableId, "" when cleared
    public event Action<string, string> EdgeAddRequested;     // (sourceId, targetId)
    public event Action<string, string> EdgeRemoveRequested;  // (sourceId, targetId)
    public event Action<string, Vector2> NodePositionChanged; // (id, position)
}
```

### Constructor wiring
```csharp
this.AddManipulator(new ContentZoomer { minScale = 0.25f, maxScale = 2f });
this.AddManipulator(new ContentDragger());
this.AddManipulator(new SelectionDragger());
this.AddManipulator(new RectangleSelector());

var grid = new GridBackground();
Insert(0, grid);
grid.StretchToParentSize();

styleSheets.Add(AssetDatabase.LoadAssetAtPath<StyleSheet>(
    "Packages/com.<vendor>.assembly-architect/Editor/UI/AsmDefGraphView.uss"));
```

### Populate
1. `Clear()` first.
2. For every `AsmDefNodeModel`, create a placeholder `Node` (the real `AsmDefNode`
   class arrives in Task 3.2, but for now use plain `Node` so the graph shows up).
3. Apply `positions[id]` to `node.SetPosition(new Rect(pos, defaultSize))`. If a
   position is missing for a node, place it at the origin offset by `(50, 50) * index`.
4. For every `AsmDefEdgeModel`, instantiate a plain `Edge`, connect the two nodes'
   default ports (created via `Port.Create`).
5. Call `RefreshExpandedState()` and `RefreshPorts()`.

### Selection forwarding
- Subscribe to `OnSelectionChanged` (override) — when one node is selected, emit
  `NodeSelected(node.userData as string)`. When zero nodes selected, emit
  `NodeSelected("")`.

### Wiring in the window
- In `AssemblyArchitectWindow.CreateGUI`, after the toolbar is added:
  ```csharp
  _graphView = new AsmDefGraphView { name = "asmdef-graph" };
  _graphView.style.flexGrow = 1;
  root.Q<VisualElement>("graph-host").Add(_graphView);
  ```
- `Populate` is called with empty data for now (`DependencyGraphModel.Empty` — add a
  static `Empty` to the model in this task if it does not already exist).

## Acceptance criteria
- Opening the window shows a grid background and a working pan/zoom area.
- Calling `Populate` with a hand-built model containing 3 nodes and 2 edges in a one-
  off menu item (`MenuItem("Tools/AA/Demo Populate")`) renders three boxes connected
  by lines. Remove the menu item before committing if it was only used for dev-checks.
- Console clean.
