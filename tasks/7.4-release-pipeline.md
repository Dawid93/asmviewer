# Task 7.4 — Release pipeline (1.0.0)

## Goal
Produce the first public release: bump versions, tag, document distribution paths.

## Files to edit
- `Packages/com.<vendor>.assembly-architect/package.json`
- `Packages/com.<vendor>.assembly-architect/CHANGELOG.md`
- `README.md` at the package root

## Specification

### Version bump
In `package.json`, set `"version": "1.0.0"`. Confirm the `unity` field still reads
`6000.0`.

### `CHANGELOG.md`
Move every entry under `[Unreleased]` into a new `## [1.0.0] - YYYY-MM-DD` block at
the top (under "Keep a Changelog" sections like Added / Changed / Fixed). Leave a
fresh empty `[Unreleased]` block above it for future work.

### Git tag
- Create an annotated tag: `git tag -a v1.0.0 -m "Assembly Architect 1.0.0"`.
- **Do not push without explicit user confirmation.**

### `README.md` distribution recipes
Add a top-level section "Publishing & Distribution" with the following subsections;
keep them as instructions for **the package author**, not the end user.

#### Git URL install
> Consumers can install by adding to `Packages/manifest.json`:
> ```json
> "com.<vendor>.assembly-architect": "https://github.com/<vendor>/assembly-architect.git#v1.0.0"
> ```

#### Local tarball
> Run `npm pack` from the package folder to produce a tarball. Distribute the
> resulting `.tgz` and instruct users to add it via Package Manager ▸ "+" ▸
> "Add package from tarball...".

#### OpenUPM submission
> Fork `openupm/openupm` and add an entry under `data/packages/com.<vendor>.assembly-architect.yml`.
> Pin the registry to your fork during testing, then open a PR.

#### Asset Store packaging
> 1. Open the project, switch to a clean Unity 6 install.
> 2. Right-click the package in **Project ▸ Packages**, choose **Export Package…**
>    (this requires the package to be embedded, not in the cache — keep it under
>    `Packages/` in your distribution branch).
> 3. Use the Asset Store Tools package to upload under category
>    **Tools ▸ Utilities**, with screenshots from `Documentation~/images/`.

### Final smoke test before tagging
- Open a brand-new empty Unity project.
- Add the package by Git URL.
- Open **Window ▸ Analysis ▸ Assembly Architect**.
- Import the **Cycle Demo** sample.
- Verify the cycle banner appears.

## Acceptance criteria
- `package.json` reads `1.0.0`.
- `CHANGELOG.md` has a populated `1.0.0` section and an empty `Unreleased` section.
- Tag `v1.0.0` exists locally.
- README contains complete distribution instructions.
- Smoke test passes.

## Out of scope
- Pushing the tag (requires user authorization).
- Uploading to the Asset Store or OpenUPM (manual step).
