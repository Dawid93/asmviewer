# Task 5.5 — Project Settings provider

## Goal
Expose package-wide preferences in **Project Settings ▸ Assembly Architect**.

## Files to create
- `Editor/Settings/AssemblyArchitectSettings.cs`
- `Editor/Settings/AssemblyArchitectSettingsProvider.cs`
- `Editor/UI/AssemblyArchitectSettings.uxml`

## Specification

### `AssemblyArchitectSettings : ScriptableSingleton<AssemblyArchitectSettings>`
Stored at `ProjectSettings/Packages/com.<vendor>.assembly-architect/Settings.asset`
via `[FilePath]` attribute:
```csharp
[FilePath("ProjectSettings/Packages/com.<vendor>.assembly-architect/Settings.asset",
          FilePathAttribute.Location.ProjectFolder)]
internal sealed class AssemblyArchitectSettings : ScriptableSingleton<AssemblyArchitectSettings> {
    public LayoutKind DefaultLayout = LayoutKind.Hierarchical;
    public bool       FailBuildsOnCycles = false;
    public bool       LayoutCacheIsTeamShared = true;   // when false, store under UserSettings/
    public Color      ProjectNodeColor   = new(0.30f, 0.63f, 1f);
    public Color      EmbeddedPkgColor   = new(0.63f, 0.42f, 1f);
    public Color      RegistryPkgColor   = new(0.53f, 0.53f, 0.53f);
    public Color      CycleEdgeColor     = new(1f, 0.55f, 0.26f);
    public Color      BrokenColor        = new(1f, 0.30f, 0.30f);
    public int        ForceLayoutIterations = 200;

    public new void Save(); // expose protected Save() for the provider
}
```

### `AssemblyArchitectSettingsProvider`
```csharp
internal static class AssemblyArchitectSettingsProvider {
    [SettingsProvider]
    public static SettingsProvider Create() {
        var provider = new SettingsProvider("Project/Assembly Architect", SettingsScope.Project) {
            label = "Assembly Architect",
            keywords = new HashSet<string>(new[] { "asmdef", "graph", "cycle" }),
            activateHandler = (search, root) => Build(root)
        };
        return provider;
    }
    private static void Build(VisualElement root) { /* load UXML, bind fields */ }
}
```

### UXML layout
- Group: **Layout** (default kind dropdown, force iterations).
- Group: **Visualization** (color fields).
- Group: **Build** (FailBuildsOnCycles toggle + helpbox: "When enabled, builds fail
  if any dependency cycle exists between project asmdefs. Cycles in package code are
  ignored.").
- Group: **Storage** (LayoutCacheIsTeamShared toggle + helpbox explaining the path
  switch).
- Bottom-right "Reset to defaults" button.

### Color propagation
- `AssemblyArchitectSettings` raises an event `Changed` whenever any field is mutated.
- `AsmDefGraphView` subscribes and re-applies USS variables on its
  `customStyle.SetVariable("--aa-color-project", color)` etc. — define those
  variables in `AsmDefGraphView.uss` and reference them from node/edge USS classes.

### Layout-cache path switch
- When `LayoutCacheIsTeamShared` toggles, move the file from
  `ProjectSettings/...` to `UserSettings/...` (or vice versa) on save. Implement in
  `LayoutCache` by deriving the path from settings.

## Acceptance criteria
- **Edit ▸ Project Settings ▸ Assembly Architect** opens the page with all fields
  visible and bindable.
- Changing colors immediately recolors nodes/edges in the open Architect window.
- Toggling "Team-shared layout" relocates the layout file to the correct folder on
  next save.
- "Reset to defaults" restores every field.
- Console clean.

## Out of scope
- Build-time enforcement of `FailBuildsOnCycles` (Task 7.3 wires the build hook).
